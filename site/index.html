Votos depois das 17h

Quantos votos as urnas registraram depois das 17h (horário de Brasília), onde isso aconteceu e quanto pesou para cada candidato.

O que aconteceu no 2º turno

  1. No domingo, 25/10, o ministro Cristiano Zanin (STF) autorizou que a votação fosse até as 19h, horário de Brasília, em todo o país, mas só nas seções que ainda estivessem abertas. A prorrogação não foi restrita ao Nordeste.
  2. As duas campanhas tinham pedido prorrogação: a de Lula citou problemas no transporte de eleitores; a de Flávio Bolsonaro pediu para 17 cidades de SP, PR e SC atingidas por chuvas.
  3. O TSE só comunicou os TREs às 17h49, quando a maior parte das seções já tinha encerrado.
  4. Mesmo sem prorrogação, quem está na fila às 17h recebe senha e vota depois desse horário (Código Eleitoral, art. 153). Por isso toda eleição tem votos após as 17h, como mostra o 1º turno.

Metodologia

De onde vêm os dados

Só dados oficiais do TSE, de todas as urnas. Não há amostra, projeção nem estimativa.

  • Resultado oficial: API de resultados do TSE (resultados.tse.jus.br), Brasil, UF e município, para Presidente nos dois turnos.
  • Log (log.jez) e Boletim de Urna (bu.dat) de cada seção. O log tem a hora de cada voto computado; o boletim tem o resultado da seção e os horários de abertura e encerramento.
    • 1º turno: pacote consolidado "Arquivos transmitidos para totalização" do Portal de Dados Abertos (dadosabertos.tse.jus.br), com os arquivos de todas as urnas totalizadas.
    • 2º turno: enquanto esse pacote não é publicado, os mesmos arquivos são baixados seção por seção da API de resultados. Quando o pacote sair, ele passa a ser a fonte.

Como os números são calculados

  • Horário: desde 2022 a votação segue o horário de Brasília em todo o país (8h às 17h), mas o relógio de cada urna marca a hora local. Por isso o Acre vota das 6h às 15h; AM (exceto 11 municípios no fuso do Acre), RR, RO, MT e MS, das 7h às 16h; e Fernando de Noronha, das 9h às 18h. Cada horário do log e do boletim é convertido para Brasília usando esse fuso fixo por município, como na regra do TSE. Não usamos a hora de abertura para deduzir o fuso, porque uma seção que abre atrasada pareceria estar em outro fuso.
  • Votos após as 17h: contamos as linhas "O voto do eleitor foi computado" do dia da eleição com horário a partir de 17h00 (Brasília). Quando uma urna é trocada no meio do dia, os logs de todas as urnas da seção são somados.
  • Urnas tardias: seções com encerramento oficial (Boletim de Urna) às 17h49 ou depois, horário de Brasília, que é a hora em que o TSE avisou os TREs da prorrogação. O boletim dessas seções é baixado sempre, para usar o horário oficial e o resultado da seção. A lista com cada urna está no CSV da seção.
  • Contagem parcial: enquanto um turno não foi todo processado, os números valem só para as seções já processadas, e o site mostra quantas são. Nada é extrapolado.
  • Por candidato: o voto é secreto, então não há divisão dos votos após as 17h entre candidatos. O site mostra o resultado oficial das seções onde houve voto após as 17h e o máximo que esses votos poderiam representar.
  • Seções agregadas: algumas seções votam junto com outra e não têm log próprio; os eleitores delas aparecem no log da seção principal.
  • Exterior: as seções no exterior ficam fora da análise de horário, porque cada país vota no seu horário local.
  • Brancos, nulos e abstenção: números oficiais da API de resultados do TSE (Brasil, UF e município). Brancos e nulos são do voto para Presidente, em % do comparecimento; abstenção é em % do eleitorado apto. Quando os boletins em massa já estão baixados, os números por município são somados seção a seção, e conferem com a API.
  • Conferência: o comparecimento contado no log e os votos lidos do boletim de cada seção são comparados com o arquivo oficial de Boletins de Urna do Portal de Dados Abertos.

Como atualizar

Na pasta do projeto:

python pipeline/atualizar.py

O script baixa o resultado oficial e, para cada turno, processa o pacote consolidado do TSE quando ele existe; se ainda não existe, continua o download seção por seção pela API. Depois recalcula o site.

Análise independente, sem vínculo com o TSE. Código-fonte e instruções para refazer a análise em github.com/ThiagoGCalistro/eleicoes-2026.
